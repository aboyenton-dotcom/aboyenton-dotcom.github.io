# Erebus Trial 2 Sync

A private, single-user tool for copying committed files from a GitHub repository into a Google Drive folder selected by the account owner.

Once configured and authorized, the tool runs through GitHub Actions and uses rclone to add or update files in the configured destination. It preserves Drive-only files and checks copied files against the source. It does not provide a public login or file-sharing service.

Google authorization is completed locally by the account owner. This documentation website does not collect credentials or provide an authorization form.

The Google Drive permission requested can access existing Drive files broadly. The copy workflow itself targets one configured destination folder. These documentation pages do not expose the source repository, copied files, or authorization credentials.
